# 星辰二手书微信小程序

面向大学校园的二手教材与课外书信息撮合小程序。平台不接入微信支付，核心流程为：

```text
发布书籍 → 同校浏览与搜索 → 收藏/我想要 → 受控查看联系方式 → 线下交易
```

## 已实现

- 原生微信小程序，三 Tab：首页、发布、我的
- 首页分类、双列书架、下拉刷新、触底分页、空/错/加载状态
- 书名、作者、出版社、ISBN 搜索及本地搜索历史
- 书籍详情、浏览记录、收藏、分享、购买意向、受控联系方式
- 发布图片、ISBN 扫码、表单校验、草稿、防重复提交
- 头像昵称填写、全国高校/校区三级选择、账号注销与资料删除、我的发布、收藏、浏览足迹
- 售出/下架、反馈、举报、关于与交易安全提示
- Mock 演示仓库与微信云开发双模式
- `user`、`book`、`engagement`、`moderation` 四个独立云函数

## 直接体验 Mock 模式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件所在的 `星辰二手书小程序/`。
4. `project.config.json` 当前使用 `touristappid`，可直接用于界面演示；也可替换为你自己的小程序 AppID。
5. 确认 `miniprogram/config/env.js` 中：

```js
module.exports = {
  enableCloud: false,
  cloudEnvId: '',
  pageSize: 6
};
```

Mock 模式无需服务器、域名或云环境，发布、收藏、足迹和反馈保存在当前设备本地缓存中。清除开发者工具缓存后，Mock 用户数据会重置。

## 切换微信云开发

1. 将 `project.config.json` 的 `appid` 替换为正式小程序 AppID。
2. 在微信开发者工具中开通云开发并创建开发环境。
3. 按 `cloudfunctions/CLOUD_SETUP.md` 创建集合、索引和加密环境变量。
4. 分别部署四个云函数。
5. 修改 `miniprogram/config/env.js`：

```js
module.exports = {
  enableCloud: true,
  cloudEnvId: '你的云环境ID',
  pageSize: 6
};
```

6. 清除本地缓存，重新编译并用两个不同微信账号进行真机测试。

## 隐私与提审前必做

在小程序管理后台配置《小程序用户隐私保护指引》，按实际功能声明：

- 用户主动填写的昵称和选择的头像
- 用户选择上传的书籍或举报图片
- 卖家主动填写的微信号或手机号
- 用户发布内容、反馈与举报内容
- 为安全审计和运营维护产生的必要操作日志

同时必须：

- 确认个人主体当前可选类目与实际服务一致，不要直接照搬旧攻略中的类目。
- 明确展示“平台仅提供信息撮合，不提供支付或交易担保”。
- 配置文本和图片内容安全、举报、下架、账号与个人信息删除流程。
- 准备可用的真实测试数据和完整审核操作说明。
- 真机测试 `chooseAvatar`、昵称填写、图片选择、扫码、分享和剪贴板权限。

## 高校与校区数据

- 高校底表采用教育部《全国普通高等学校名单（截至2026年6月17日）》，覆盖中国内地普通高校 2952 所、31 个省级区域。
- 教育部该名单明确不含中国香港、中国澳门、中国台湾地区高校，因此本地选择器当前范围与官方底表保持一致，不将其误标为“全国所有高校”。
- 校区参考由公开地图 POI 与开源高校地理补充数据交叉整理：2503 所高校有参考校区，共 3239 条参考校区；其余学校及新增/撤并校区可选择“其他校区（手动填写）”。
- 校区数据不是教育部官方校区名录，资料页会提示用户核对；数据来源和边界见 `miniprogram/subpackages/account/data/DATA_SOURCE.md`。
- 高校及校区数据位于账号分包，不进入主包。

## 云端数据安全

- 页面只调用 `services/`，不直接读写云数据库。
- 所有写操作通过云函数并以服务端 OpenID 判断身份。
- 公开书籍详情不返回 OpenID 或联系方式。
- 联系方式独立存入 `seller_contacts`，使用 AES-GCM 加密，经受控云函数读取并记录审计。
- 文本安全接口失败时拒绝写入，不默认放行。

## 当前已知限制

- 未接入微信支付、即时聊天、物流、地图或复杂推荐，这是产品边界而非缺陷。
- Mock 封面主要使用纸张色占位，避免引入二进制素材和包体膨胀；用户发布图片可正常显示。
- 云端搜索是适合 MVP 的关键词数组匹配，不是全文检索；数据量增大后应迁移专用搜索能力。
- 图片异步内容安全回调和自动复审流程尚未完成，正式提审前必须补齐或采用人工先审后发。
- 当前未提供独立 Web 运营后台，可先使用云开发控制台处理审核与下架。

## 推荐联调顺序

1. 首页浏览与搜索
2. 发布一本书并回到首页
3. 打开详情、收藏和查看联系方式
4. 在“我的发布”标记售出或下架
5. 测试反馈、举报与浏览足迹
6. 切换云模式后用两个微信账号重复以上流程

## 性能目标

- 主包控制在 1.5MB 内
- 中端 Android 首屏可交互时间目标低于 1.5 秒
- 列表按 6 条分页，图片懒加载，页面批量 `setData`
- 开发者工具性能评分目标不低于 90
