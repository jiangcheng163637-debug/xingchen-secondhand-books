# 高校与校区数据说明

- 高校底表：中华人民共和国教育部《全国普通高等学校名单（截至2026年6月17日）》，共2952所。来源：`https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202606/t20260618_1441074.html`。
- 官方名单范围：中国内地普通高等学校；该名单明确不含中国香港、中国澳门、中国台湾地区高校。
- 校区参考：公开地图 POI 与 `Naptie/cn-university-geocoder` 的 `univ_supp.json`（MPL-2.0）交叉整理，参考仓库：`https://github.com/Naptie/cn-university-geocoder`。地图 POI 仅保留严格匹配学校官方名称的校区名；其余学校仅提供校本部参考或手动填写。该数据不是教育部官方校区名录。
- 未匹配、新增、撤并或更名校区，前端提供“其他校区（手动填写）”。
- 数据更新后必须由运营抽样核验，用户选择前也会收到核对提示。
